## ✅ code-5: what's the difference between == and === in javascript
**Maple said:**
> In JavaScript, `==` and `===` are both used to compare values, but they do so in different ways:
> 
> - **`==` (equality operator)**:
>   - Coerces both operands to the same type before comparing them.
>   - This means it will convert numbers to strings, strings to numbers, or perform other type conversions as needed to make the comparison.
>   - Example:
>     ```javascript
>     "3" == 3; // true, because "3" is converted to 3
>     3 == "3"; // true, same as above
>     4 == false; // false, because 4 is not false
>     ```
> 
> - **`===` (strict equality operator)**:
>   - Requires both the value and the type to be exactly the same.
>   - Does not perform any type coercion. If the types are different, it will return false immediately.
>   - Example:
>     ```javascript
>     "3" === 3; // false, because "3" and 3 are of different types
>     4 === false; // false, because 4 and false are of different types
>     ```
> 
> In summary, `===` is more strict and only returns true if both the value and the type are the same, whereas `==` will perform type coercion before comparing the values.

**Expected:** == compares after type conversion; === compares value and type without conversion.
