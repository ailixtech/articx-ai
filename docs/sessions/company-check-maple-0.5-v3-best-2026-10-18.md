## ✅ code-5: what's the difference between == and === in javascript
**Maple said:**
> In JavaScript, `==` and `===` are both used to compare values, but they do so in different ways:
> 
> - **`==` (equality operator)**:
>   - Performs type coercion, which means it attempts to convert the operands to a common type before comparing them.
>   - For example, `5 == "5"` is `true` because the string "5" is coerced to the number 5.
>   - This can lead to unexpected results because of the type coercion.
> 
> - **`===` (strict equality operator)**:
>   - Does not perform type coercion. It requires both the values and their types to be exactly the same for the comparison to be `true`.
>   - For example, `5 === "5"` is `false` because the number 5 and the string "5" are of different types.
>   - This is generally safer and more predictable for comparisons.
> 
> In most cases, it's recommended to use `===` for comparisons to avoid unexpected type coercion.

**Expected:** == compares after type conversion; === compares value and type without conversion.

> - The second part of the pattern `^A[0-9][0-9] [0-9][ABCEFGHJKMNPRSTVWXY]$` covers the rare format starting with "A" followed by two digits and a space, followed by a digit and a letter.
